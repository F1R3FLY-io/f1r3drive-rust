## Open findings

1. `cargo deny` wildcard errors: workspace crates do not set `publish = false`, so cargo-deny treats their path dependencies as wildcards.
2. RUSTSEC-2026-0387 (crypto-bigint 0.5.5 through k256/p256 0.13). f1r3node-rust uses k256/p256 0.14 and crypto-bigint 0.7.6.
3. RUSTSEC-2025-0161 (libsecp256k1 unmaintained, used by f1r3drive-crypto). f1r3node-rust does not use it.
4. 23 commits on main carry `Co-Authored-By: Claude ... <noreply@anthropic.com>`. CI checks only pull request commits, so they do not fail, but new commits in that form will.
5. The local machine has no fuse-t, so the fuse-linked crates were not tested locally. CI tests them on both platforms.
